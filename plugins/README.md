# Плагины FrogeeCodeIDE

Плагины устроены так же, как в FgSNotes: это файлы `.js` и `.css` в папке

- macOS / Linux: `~/Documents/FrogeeCodeIDE/plugins`
- Windows: `Документы\FrogeeCodeIDE\plugins`

## Установка

Настройки → Плагины → **Установить…** → выберите один или несколько файлов. Редактор предупредит, что плагин выполняется внутри него, скопирует файлы в папку плагинов и сразу их включит.

Файл можно положить в папку и вручную: он появится в списке выключенным, включите его переключателем. «Удалить» нужно нажать дважды, файл уходит в корзину.

Плагин — это программа с правами редактора: он видит открытые файлы. Ставьте только те плагины, которым доверяете.

## Как написать плагин

`.css` просто добавляется на страницу.

`.js` — тело функции, которая получает API в переменной `frogee` (и `fgs`, поэтому плагины FgSNotes работают без изменений). В начале файла — шапка с описанием:

```js
// ==FrogeePlugin==
// @name        Вставить дату
// @version     1.0
// @description Кнопка на левой панели вставляет сегодняшнюю дату
// @author      Вы
// ==/FrogeePlugin==
frogee.addButton({
  title: 'Вставить дату',
  icon: 'calendar',
  run: (editor) => editor.insert(new Date().toLocaleDateString('ru-RU')),
});
```

## API

| Вызов | Что делает |
| --- | --- |
| `addButton({ title, icon, run })` | Кнопка на левой панели. Если кнопок больше, чем помещается, остальные уходят в меню «…». `icon` — имя (`sparkles`, `edit`, `draw`, `calendar`, `history`, `clock`, `code`, `image`, `star`, `bolt`, `list`) или разметка SVG. `run(editor)` вызывается по нажатию. |
| `addStyle(css)` | Добавляет CSS, пока плагин включён. |
| `editor.get()` / `editor.set(text)` | Весь текст открытого файла. |
| `editor.insert(text)` | Вставляет текст вместо выделения. |
| `editor.selection()` / `editor.cursor()` | Выделенный текст / `{ from, to }`. |
| `editor.replace(from, to, text)` | Заменяет кусок текста. |
| `editor.file()` | `{ name, path, extension }` открытого файла или `null`. |
| `onChange(fn)` | `fn(text)` после каждого изменения текста. |
| `onTabChange(fn)` | `fn(file)` при переключении вкладки. |
| `onPreview(fn)` | `fn(element)` после каждой перерисовки предпросмотра Markdown. |
| `storage.get(key, fallback)` / `storage.set(key, value)` | Небольшое хранилище плагина. |
| `notify(text)` | Короткое сообщение внизу окна. |
| `onUnload(fn)` | `fn()` при выключении или удалении плагина. |

Методы `editor` работают, когда открыт текстовый файл; иначе кнопка покажет сообщение «Откройте текстовый файл».

## Примеры

- `exildraw.js` — доска для набросков в духе Excalidraw: перо, линии, стрелки, фигуры, текст. Рисунок вставляется в Markdown-файл как SVG; поставьте курсор на строку с рисунком и нажмите кнопку или щёлкните по нему в предпросмотре, чтобы поправить. Работает без интернета.
- `insert-date.js` — кнопка вставляет текущую дату и время.
