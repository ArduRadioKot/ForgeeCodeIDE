# Changelog

## 1.1.0

### Дизайн
- Единая система оформления в стиле JetBrains Islands (тёмная и светлая темы), общие токены в `styles/tokens.css`.
- Liquid Glass из MarkdownEditor: прозрачное окно (vibrancy в macOS, acrylic в Windows 11), стеклянная подложка и «острова», мягкие реакции кнопок. Пресеты, плотность, размытие и качество настраиваются в Настройки → Внешний вид; вкл/выкл через палитру команд.

### Интерфейс
- Цвет по умолчанию снова бирюзовый (`#21aabe`); ссылки и выделение строятся от выбранного акцента.
- Боковое меню: повторный клик по активной кнопке сворачивает панель, заголовки на русском, ошибки панели показываются внутри неё. Ширину панели можно менять перетаскиванием границы (двойной клик — сброс).
- Убрана заглушка «Расширения». Вместо пустой «отладки» — рабочая панель «Запуск»: текущий файл, скрипты `package.json`, Live Server, браузер.
- Git починен: панель не открывалась из-за необъявленной переменной. Добавлены ветки (переключение и создание), diff по клику, откат файла, счётчики ↑/↓, последние коммиты, корректные пути с пробелами и кириллицей.
- Jupyter: убраны лишние пустые строки в ячейках, ровные поля и панель инструментов без переносов.
- Выделение текста: цветной текст рисуется поверх выделения, цвета синтаксиса не тускнеют; высота строки целая, без «швов» между строками; в неактивном окне выделение серое; выделение в терминале следует за акцентом.
- Шрифты редактора и интерфейса (список с проверкой установки или свой), лигатуры.
- Пользовательские темы из JSON: папка `~/Documents/FrogeeCodeIDE/themes`, импорт, пример `themes/dracula.json` и описание формата в `themes/README.md`.
- Анимации только у левого тулбара и верхних вкладок: подсветка плавно «перетекает» между ними. Остальные переходы убраны (остались лишь индикаторы загрузки).
- Компактный UI теперь действительно плотнее: ниже вкладки, строки дерева, заголовки, кнопки, поля настроек, строка состояния, уже полоса иконок, меньше отступы и скругления.
- Темы: Dracula встроена и доступна всегда (файл в папке пользователя её заменяет); если папку тем прочитать не удалось, в настройках показывается причина.

### Браузер в сплите
- Браузер можно вынести рядом с редактором или ноутбуком: кнопка в панели браузера, меню вкладки («Открыть рядом с редактором»), `Ctrl/Cmd+\\` или палитра команд. Страница при этом не перезагружается.
- Live Server и F5 на HTML-файле открывают превью справа от кода. Ширину панелей можно менять перетаскиванием, закрытие браузера возвращает редактор.
- Live Server теперь пропускает порты, занятые другими программами (например, VS Code Live Server на 5500), а не «делит» их с ними.

### Разделённый редактор
- Правая панель больше не пропадает после перехода на ноутбук, браузер или терминал.
- Есть активная панель: вкладки и файлы из проводника открываются в ту, где вы работаете. Контекстное меню вкладки: «Открыть справа / слева», «Поменять панели местами», «Закрыть остальные».
- Один файл в двух панелях редактируется синхронно, Ctrl/Cmd+S сохраняет файл активной панели. Шрифт и табуляция одинаковы в обеих панелях.

### Подсветка синтаксиса
- Новый токенизатор: комментарии и строки больше не ломают разметку (исправлена подсветка CSS и вложенных конструкций).
- 30+ языков и форматов: JS/TS/JSX/TSX, Python, Java, Kotlin, Scala, C, C++, C#, Go, Rust, Swift, Dart, PHP, Ruby, Lua, R, PowerShell, SQL, Shell, HTML/XML/Vue (со встроенными script и style), CSS/SCSS/Less, JSON, YAML, TOML, INI, Markdown (с кодом в блоках), Dockerfile, Makefile, Diff.

### Jupyter-ноутбуки
- Постоянное Python-ядро: переменные сохраняются между ячейками, `!shell`, `%pip`, графики matplotlib, таблицы pandas.
- Вставка блоков между ячейками, очередь выполнения, прерывание и перезапуск ядра, горячие клавиши Jupyter.
- Оглавление и инспектор переменных. HTML-выводы очищаются от скриптов.

### Редактор
- Автозакрытие скобок, кавычек и HTML-тегов, автоотступ, блочный Tab, комментирование, перемещение и дублирование строк.
- Палитра команд (Ctrl/Cmd+Shift+P), быстрое открытие файла (Ctrl/Cmd+P), переход к строке и к символу (Ctrl/Cmd+Shift+O).
- Поиск и замена, переименование слова во всём файле, форматирование (JSON и очистка пробелов), сортировка строк, смена регистра.
- Список TODO/FIXME по проекту, повторное открытие закрытой вкладки, скрытие боковой панели (Ctrl/Cmd+B), режим без отвлечений.
- Автосохранение, запуск файла по F5, копирование пути.

### Встроенный браузер и Live Server
- Вкладка-браузер с адресной строкой, режимами устройств, консолью страницы и инструментами разработчика.
- Live Server на 127.0.0.1: мгновенная замена CSS и перезагрузка страницы при изменении файлов. Запуск из статус-бара, палитры, F5 для HTML и контекстного меню проводника.

### Кодовые агенты
- Claude Code и Codex отвечают в AI-чате, работая в папке проекта (режимы «только чтение» и «правка файлов»).
- OpenCode: запуск `opencode serve` из настроек с автоподбором свободного порта.
- Запуск любого агента в терминале проекта, готовые запросы по выделенному коду.
- Чат показывает ответы в Markdown с потоковым выводом; сообщения очищаются от опасной разметки.
