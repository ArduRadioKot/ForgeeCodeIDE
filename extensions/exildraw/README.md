# Exildraw для FrogeeCodeIDE

Доска для набросков в духе Excalidraw: перо, линии, стрелки, прямоугольники, эллипсы, текст и ластик.

- Кнопка «Рисунок (Exildraw)» на левой панели открывает доску.
- «Вставить» кладёт рисунок в Markdown-файл как SVG.
- Чтобы поправить рисунок, поставьте курсор на его строку и нажмите кнопку или щёлкните по нему в предпросмотре.
- Работает без интернета.
